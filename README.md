# Нейра — своя ИИ на компьютере

Чат с искусственным интеллектом, который работает **прямо на твоём ПК**:
без подписок, без API-ключей и без интернета (после первой загрузки).
Твои сообщения никуда не отправляются.

## Скачать

👉 **[Скачать MoyaII.exe](../../releases/latest)**: открой страницу и нажми на `MoyaII.exe` в разделе *Assets*.

## Как пользоваться

1. Создай отдельную папку, например `Нейра`, и положи туда `MoyaII.exe`.
2. Запусти `MoyaII.exe`.
3. При первом запуске приложение само скачает:
   - движок для видеокарты (~50 МБ);
   - модель на выбор: **Быстрая** (1.3 ГБ) или **Умная** (2.7 ГБ).
4. Готово, можно общаться. Дальше всё работает без интернета.

> Windows может показать окно «Система Windows защитила ваш компьютер»: приложение новое и пока не подписано.
> Нажми **«Подробнее» → «Выполнить в любом случае»**.

## Возможности

- ⚡ Работает на видеокарте (NVIDIA, AMD, Intel) через Vulkan, а если видеокарты нет, то на процессоре
- 🧠 Несколько моделей, переключение в один клик
- 💾 Помнит разговор между запусками (кнопка «Забыть всё» стирает память)
- 🔒 Полностью офлайн, данные не покидают компьютер

## Требования

- Windows 10 / 11 (64 бит)
- 8 ГБ оперативной памяти (лучше 16)
- Видеокарта желательна (от 2–4 ГБ видеопамяти), но не обязательна
- 2–4 ГБ свободного места на диске

## Собрать самому

Нужен [Python 3](https://python.org) (при установке отметь «Add Python to PATH»).
Положи `moya_ii.py` и `sobrat_prilozhenie.bat` в одну папку и запусти `sobrat_prilozhenie.bat`.

Имя ИИ и её характер меняются в блоке `НАСТРОЙКИ` в начале `moya_ii.py`.
